# 運営本の編集用テンプレート

このパッケージは、既存の一業務へ「目的、所有者、公式確認、次の一手」を置くための雛形です。実行エンジン、認証機能、スケジューラ、決済機能は含みません。

## 最初にすること

1. TASK.md に一つの成果と完了条件を書く。
2. ROLE.md と OWNERS.csv で現在の担当と対象を決める。
3. RUNBOOK.md の入力と確認先を、自分の実際の業務に合わせて埋める。
4. 一件だけ完了させ、EVENT.example.json と EFFECTS.csv の形で根拠を残す。
5. 失敗は FAILURE.md、交代は HANDOVER.md、日次報告は DAILY.md へ記録する。

設定の null と未記入欄は、無制限や無料を意味しません。所有者が有効な値と根拠を設定してから実行します。例のIDは架空で、実在するサービスを呼び出す値ではありません。

秘密値、顧客情報、個人の連絡先をテンプレートへ書かないでください。秘密の保存先は運用環境にある一つの正本を使い、値ではなく照合した結果だけを残します。

本文と雛形は自身の個人・商用の運用へ編集して使えます。未変更の本文やパッケージをそのまま再販売することは含みません。ソースは公開リポジトリでも閲覧できます。有料版は整形済み本文とダウンロード用パッケージです。
