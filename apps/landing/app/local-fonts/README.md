# Local fonts

These Latin WOFF2 subsets keep the Next.js build independent of Google Fonts network access. The existing pages requested only the `latin` subset; Japanese glyphs continue to use the browser's system fallback. Each family is licensed under the SIL Open Font License; the exact license text is in `licenses/`.
