# Life Manager Cloud — Web-first短尺動画台本

日本向けのTikTok・Instagram Reels・YouTube Shorts用。1本1アイデア、縦9:16、20秒前後。各台本は独立して見ても伝わる構成にする。

## 共通の商品事実

- CTAは `aniccaai.com/lm` の **「Google Calendarに接続」**。
- Googleアカウントの確認とCalendar権限の許可が必要。Life ManagerはGmailを読まない。
- 接続後は同じページに接続完了と7日間無料トライアルを表示する。トライアル開始にはカード登録が必要で、7日後から既存価格の$29/月が自動請求される。
- 毎日の利用面はGoogle Calendar。Webダッシュボード、scan画面、再scan操作、Telegram必須、電話発信は見せない。
- 予定の場所と経路を確認できる場合だけTravel blockを示す。場所を推測せず、すべての予定に必ず追加されるとは言わない。
- デモには合成予定と合成場所だけを使う。実カレンダー、実住所、顧客の予定名、通話録音は使わない。

## 配信前チェック

- 各動画の冒頭2秒で痛みか具体的な出発時刻を見せる。字幕は音声なしでも理解できるようにする。
- 各masterとcaptionは別の内容・固有UTMにする。重複動画や同文投稿を量産しない。
- 価格は既存の$29/月のまま。$20、通話、Telegram必須、ログイン不要とは書かない。
- Live posting前にWeb OAuth→Calendar→Stripe trialの実経路を確認する。既存TikTok投稿のeffect unknown fenceが閉じるまでは同じ投稿を再送しない。
- 現在の制作対象は日本語。英語版は別captions/素材として翻訳し、字幕とCTAを日本語版の機械的複製にしない。
